# Astra AI roadmap

## Phase 1 — usable foundation
- [x] Responsive chat workspace
- [x] Server-side AI chat endpoint
- [x] API key stays on the server
- [ ] Deploy to hosting and configure environment variables
- [ ] Automated tests and CI

## Phase 2 — reliable workspace
- [ ] Conversation history and account authentication
- [ ] User-controlled persistent memory with inspect/edit/delete controls
- [ ] File uploads and document analysis
- [ ] Streaming responses and cancellation
- [ ] Model/provider selection

## Phase 3 — specialist capabilities
- [ ] Coding assistant with sandboxed execution and diff review
- [ ] Image generation provider integration
- [ ] Video generation provider integration
- [ ] Marketing workflows for content calendars and campaign drafts
- [ ] Explicit confirmation before sending/publishing or other consequential external actions

## Principles
- Be honest about capability boundaries.
- Keep credentials server-side.
- Require user confirmation for consequential external actions.
- Measure quality with tests rather than making unsupported claims of superiority.
